## Welcome to IBM Bobathon Amsterdam Labs

This collection of hands-on labs demonstrates how to leverage **IBM Bob** as an AI development partner to build enterprise-grade solutions. From full-stack applications to event-driven agentic systems, you'll learn how AI can accelerate your development workflow.

## About IBM Bob

IBM Bob is an AI-powered development assistant that helps developers create, deploy, and manage applications more efficiently. Bob can generate code, create documentation, design architectures, and automate deployment workflows.

### [Lab 3: Building an Event-Driven Agentic AI System with Apache Kafka on Confluent Cloud and watsonx Orchestrate](Lab%203%20-%20Building%20an%20event-driven%20agentic%20AI%20system%20with%20Apache%20Kafka%20on%20Confluent%20Cloud%20and%20watsonx%20Orchestrate/)

**Focus**: Real-time event-driven agentic systems with Kafka and watsonx Orchestrate

**🚀 [START LAB 3 NOW →](Lab%203%20-%20Building%20an%20event-driven%20agentic%20AI%20system%20with%20Apache%20Kafka%20on%20Confluent%20Cloud%20and%20watsonx%20Orchestrate/README.md)**

**What You'll Learn:**
- Build event-driven agentic AI systems
- Integrate Apache Kafka with AI agents
- Use ksqlDB for stream processing
- Create MCP toolkits for Kafka integration
- Implement agentic RAG (Retrieval-Augmented Generation)
- Build supervisor agents that coordinate multiple specialist agents
- Process real-time inventory events

**What You'll Build:**
A **Real-Time Retail Inventory System** with three coordinated agents:
- **SKU Availability Agent**: Checks real-time stock levels from Kafka streams
- **Substitute Finder Agent**: Recommends alternatives using agentic RAG
- **Store Associate Agent**: Supervisor agent coordinating the specialists

**Use Case:**
During high-demand seasons (e.g., Christmas), customers ask: "Do you have the Laptop Dell XPS in the Mall of Egypt, and if not, what's the alternative laptop?" The system provides real-time answers by:
1. Checking live inventory from Kafka events
2. Finding similar products from enterprise documents
3. Returning customer-friendly responses

**Key Technologies:**
- IBM Bob (AI development assistant)
- Confluent Cloud (Managed Apache Kafka)
- ksqlDB (Stream processing)
- watsonx Orchestrate (Agent orchestration)
- watsonx Orchestrate ADK (Agent Development Kit)
- MCP Toolkits (Kafka integration)
- Agentic RAG (Document retrieval)

**Architecture Components:**
1. **Kafka Topics**: `inventory.transactions` (source), `inventory.availability` (derived)
2. **ksqlDB**: Continuous aggregation of inventory state
3. **MCP Tool**: `get_sku_availability` for querying Kafka
4. **Enterprise Documents**: Product catalog for semantic search
5. **Multi-Agent System**: Supervisor + specialist agents

**Time Estimate**: 90-120 minutes

**Prerequisites:**
- watsonx Orchestrate ADK 2.1+ installed
- Confluent Cloud account (free trial available)
- watsonx Orchestrate instance
- IBM Bob (optional but recommended)
- Basic familiarity with Kafka concepts

**Lab Structure:**
1. Create Kafka Topic in Confluent Cloud
2. Create Derived Topic with ksqlDB
3. Publish Sample Message Events
4. Create MCP Tool and AI Agent
5. Create Agentic RAG Agent
6. Create Supervisor Agent

**Lab Materials:**
- 📄 [Complete Tutorial](Lab%203%20-%20Building%20an%20event-driven%20agentic%20AI%20system%20with%20Apache%20Kafka%20on%20Confluent%20Cloud%20and%20watsonx%20Orchestrate/README.md) (499 lines, 6 steps)
- 📋 [Agent YAML Configurations](Lab%203%20-%20Building%20an%20event-driven%20agentic%20AI%20system%20with%20Apache%20Kafka%20on%20Confluent%20Cloud%20and%20watsonx%20Orchestrate/assets/)

## Learning Path

We recommend completing the labs in order:

1. **Lab 1** (45 min) - Learn Bob basics with a simple full-stack app
2. **Lab 2** (60-75 min) - Build programmatic agents with watsonx Orchestrate
3. **Lab 3** (90-120 min) - Create event-driven multi-agent systems
4. **Lab 4** (60 min) - Experience Bob's complete SDLC capabilities (interactive demo)
5. **Lab 5** (35-40 min) - Create custom modes with specialized AI agents

**Total Time**: 4-5 hours for all labs
